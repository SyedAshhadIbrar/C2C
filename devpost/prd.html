Chaos to Clarity: Product Requirements

One screen. Messy planning notes in, a verifiable, editable action plan out. Owners, deadlines, and answers are never invented.

Scope → PRD. Scope said “users can review and edit the extracted tasks.” Now we know exactly what that means: edit the title, owner, and deadline on the card; user values are marked user-provided; delete with confirmation; User-added tasks; questions can be resolved; and AI output that doesn't match the notes is shown with a verification warning.

Look and feel

Calm, organized, trustworthy: a cluttered desk becoming an organized workspace. Modern, readable sans-serif with an obvious hierarchy. Spacious two columns, subtle borders, compact cards. Motion is subtle and fast.
warm off-white white cards charcoal text teal/sage accent amber: missing/warning red: errors only

Avoid: AI gradients, heavy glassmorphism, distracting animation, too many colors, crowded dashboards. (Swatches are illustrative; exact values are set in the spec.)

Boundary

Building now
Paste → Organize Notes → cards (source phrase, owner/deadline or explicit gaps, blocked status) + Blockers & Dependencies + Open Questions → verification warnings → edit title/owner/deadline, resolve/edit questions, delete with confirmation, Add task → export the edited plan as Markdown. Plus empty, no-tasks, and error states, one demo note set, and an ambiguity test.
Deferred
  • Dependency editing: not needed to show reliability; display-only for now
  • Undo for delete: confirmation is enough
  • Saved history, accounts, integrations, collaboration, deployment: excluded by scope
Non-goals
  • Inferring missing owners, deadlines, or answers
  • Multiple demo scenarios
  • Decoration that competes with readability

Resolved decisions

  • Relative dates: “by Friday” and “next week” count as stated deadlines and are shown exactly as written, never converted (the meeting date and timezone are unknown). Genuinely ambiguous wording → flag to clarify.
  • Export: the full edited plan: task checklist (owner, deadline, source phrase) + Blockers & Dependencies + Open Questions, with every label and warning kept. Nothing added that wasn't in the notes or entered by the user.

No open questions block 4-spec.
